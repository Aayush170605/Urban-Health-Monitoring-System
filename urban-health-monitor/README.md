# Urban Health Monitor (application)

This folder is the React + Vite source for the Urban Health Monitoring System dashboard.

The full project README — problem statement, 3-minute presentation script, formulas, architecture, and Docker instructions — is in the repository root:

**[../README.md](../README.md)**

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:5173. For the production image and viva demo, use the root README (Docker Hub / `docker compose`).
